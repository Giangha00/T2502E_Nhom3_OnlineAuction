# РАЗРАБОТКА СИСТЕМЫ УПРАВЛЕНИЯ КУРСАМИ (COURSE MANAGEMENT SYSTEM)

## 1. Цель проекта
Разработка веб-приложения для управления курсами на базе платформы **ASP.NET Core 8.0 MVC** и системы управления базами данных **MySQL**. Проект направлен на решение задач по управлению связями данных (1-N), интеграции со сторонними облачными сервисами хранения данных и обработке форматированного текста (Rich Text).

## 2. Спецификация базы данных
Система требует настройки двух основных сущностей со связью **«Один ко многим»** (Одна категория содержит множество курсов):

### 2.1. Сущность `Category` (Категория)
*   **Id (int):** Первичный ключ, автоинкремент.
*   **Name (string):** Название категории (уникальное значение, например: Информационные технологии, Экономика, Иностранные языки).
*   **Description (string):** Краткое описание категории.

### 2.2. Сущность `Course` (Курс)
*   **Id (int):** Первичный ключ, автоинкремент.
*   **Title (string):** Название курса (обязательно, минимум 10 символов).
*   **Description (string):** Краткое описание (простой текст).
*   **Content (string):** Подробное содержание (хранится в формате HTML-кода).
*   **ImageUrl (string):** Ссылка на файл изображения, хранящийся в Cloudinary.
*   **Price (decimal):** Стоимость обучения.
*   **StartDate (DateTime):** Дата начала курса.
*   **EndDate (DateTime):** Дата окончания курса.
*   **CategoryId (int):** Внешний ключ, ссылающийся на таблицу `Category`.
*   **Status (int):** Статус курса: 1 — активен, 0 — удален.

## 6. Руководство по настройке связей в моделях

Для настройки связи **«Один ко многим» (One-to-Many)** между `Category` и `Course` в Entity Framework Core разработчику необходимо сконфигурировать классы моделей (Entities) через навигационные свойства (Navigation Properties) и свойства внешнего ключа (Foreign Key).

### 1. Определение сущности `Category` (Сторона «Один»)
В этой связи одна категория может содержать много курсов. Необходимо использовать коллекцию (обычно `ICollection`) для представления списка связанных курсов.

```csharp
using System.Collections.ObjectModel;

namespace YourProject.Models;

public class Category
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;

    // Навигационное свойство: У одной категории много курсов
    public virtual ICollection<Course> Courses { get; set; } = new Collection<Course>();
}
```

### 2. Определение сущности `Course` (Сторона «Много»)
Каждый курс относится только к одной категории. Необходимо объявить как **внешний ключ (Foreign Key)**, так и **единичное навигационное свойство (Reference Navigation Property)**.

```csharp
using System.ComponentModel.DataAnnotations.Schema;

namespace YourProject.Models;

public class Course
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;

    // Свойство внешнего ключа (Foreign Key)
    public int CategoryId { get; set; }

    // Навигационное свойство: Один курс принадлежит к одной категории
    [ForeignKey("CategoryId")]
    public virtual Category? Category { get; set; }
}
```

### 3. Детальная настройка через Fluent API (Опционально, но рекомендуется)
Хотя EF Core может автоматически распознавать связи по соглашениям об именовании, использование **Fluent API** в классе `AppDbContext` помогает сделать структуру более явной и контролировать такие ограничения, как каскадное удаление.

В файле `Data/AppDbContext.cs` обновите метод `OnModelCreating`:

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    base.OnModelCreating(modelBuilder);

    // Настройка связи «Один ко многим»
    modelBuilder.Entity<Course>()
        .HasOne(c => c.Category)           // У курса одна категория
        .WithMany(cat => cat.Courses)      // У категории много курсов
        .HasForeignKey(c => c.CategoryId)  // Указание внешнего ключа CategoryId
        .OnDelete(DeleteBehavior.Restrict); // Запрет удаления категории, если на нее ссылаются курсы
}
```

### 4. Объяснение технических компонентов

*   **Ключевое слово `virtual`:** Пометка навигационных свойств как `virtual` позволяет EF Core использовать механизм **Lazy Loading** (ленивая загрузка данных только при обращении к ним).
*   **`ICollection<T>`:** Инициализация по умолчанию `new Collection<T>()` помогает избежать ошибок `NullReferenceException` при добавлении новых данных в навигационный список.
*   **`DeleteBehavior.Restrict`:** В системах управления обычно не разрешается удалять `Category`, если в ней все еще есть курсы (`Course`). Использование `Restrict` защищает целостность данных.

### 5. Способ запроса связанных данных (Eager Loading)
При получении списка курсов в контроллере для отображения названия категории в представлении (View) необходимо использовать метод `.Include()`:

```csharp
var courses = await _context.Courses
                            .Include(c => c.Category) // Запрос на включение данных категории
                            .ToListAsync();
```

### 6. Отображение списка категорий в форме создания курса

#### 1. В контроллере (Action Create)
Запросите список категорий и передайте его во View через `ViewBag` в виде `SelectList`.

```csharp
public async Task<IActionResult> Create()
{
    // Получение списка ID и Name для заполнения выпадающего списка
    var categories = await _context.Categories.ToListAsync();
    ViewBag.CategoryId = new SelectList(categories, "Id", "Name");
    
    return View();
}
```

#### 2. В представлении (Create.cshtml)
Используйте тег-хелпер `asp-items` для автоматической генерации тегов `<option>` для HTML-элемента `<select>`.

```html
<div class="form-group">
    <label>Категория курса</label>
    <select asp-for="CategoryId" class="form-control" asp-items="ViewBag.CategoryId">
        <option value="">-- Выберите категорию --</option>
    </select>
    <span asp-validation-for="CategoryId" class="text-danger"></span>
</div>
```

**Примечание:**
*   `asp-for="CategoryId"`: Привязывает выбранное значение к свойству `CategoryId` модели.
*   При использовании **ViewModel** рекомендуется передавать `IEnumerable<SelectListItem>` напрямую в ViewModel вместо использования `ViewBag`. Это делает код более профессиональным и безопасным (строгая типизация).
